SLIDE 7: (draft page 14, update steps 2 and 4 · SHEET A-007)
Header: From drawing to doorway in five steps
Text:
HOW IT WORKS (small label)
1 Read the DWG — Lines, arcs, blocks and text become a structured JSON description.
2 Classify & check — AI classifies every layer, compares a picture of the drawing with the model room by room, and
  fixes what's impossible.
3 Generate 3D — The server builds a Babylon.js scene at real-world scale, with real openings, doors and furniture.
4 Walk it — WASD and mouse in the browser, with collisions; open doors with E, step outside.
5 Edit live — Only the affected parts rebuild. No reload, no camera reset.

AI WITH GUARDRAILS (small label)
Row 1 — every edit:
YOU ASK "Make the selected window 50% wider." → AI PROPOSES a command from a small allowlist, never 3D-engine code
→ SERVER VALIDATES Does the opening still fit the wall? → SCENE UPDATES only the affected parts; Undo is one click
away.

CODE FINDS what's impossible: furniture inside walls, rooms without a door, a bathroom open to a bedroom, a missing
outer wall → CODE LISTS safe fixes → AI CHOOSES one after comparing a picture of the drawing with the model →
CODE ENFORCES it before the 3D model is built.
LLM down? Buttons, sliders and a rule-based interpreter call the same edit functions, and every check still has a
safe default.
